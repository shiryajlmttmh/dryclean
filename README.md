# Информационная система химчистки

Курсовой проект по дисциплине «Программирование на языках высокого уровня» (БГУИР, 2026).

Настольное приложение на C++20 и Qt 6 для небольшой химчистки: учёт клиентов, изделий и заказов, расчёт стоимости и сроков, умный планировщик партий обработки, складской учёт расходных материалов, учёт оборудования и сотрудников, локальное хранение данных.

## Возможности

- Вход по логину, разграничение прав по ролям сотрудников: приёмщик, оператор, администратор. При первом запуске создаётся учётная запись администратора с логином `admin`.
- Картотека клиентов с поиском по телефону и подстроке имени, персональная скидка клиента.
- Приём заказов: маркировка изделий, фиксация материала, цвета, массы, загрязнения, пятен и дефектов. Перед приёмом показываются стоимость с учётом скидки, срок выполнения и крайний срок готовности.
- Редактирование изделий уже принятого заказа, пока он не передан в обработку.
- Полиморфный расчёт стоимости и срока по видам услуг (сухая чистка, влажная чистка, выведение пятен, кожа и мех), срочные заказы.
- Цепочка статусов заказа: Принят → В обработке → Готов → Выдан. Список заказов можно отфильтровать по статусу и по просроченным.
- Планировщик партий: совместимость по ткани, цвету и режиму, вместимость машин, остатки материалов, граф конфликтов с объяснением причин, проверка плана перед подтверждением.
- Партии обработки со статусами «Запланирована» и «Завершена»; партия, время начала которой наступило, отображается как «В работе».
- Складской учёт: поиск и сортировка материалов, пополнение и списание, автоматическое списание расхода при подтверждении плана.
- Справочник машин и управление сотрудниками (с защитой от потери последнего администратора).
- Атомарное сохранение данных в локальные файлы (поколения снимка и указатель CURRENT) с проверкой целостности при загрузке. Данные хранятся в каталоге данных приложения пользователя.

## Технологии

- C++20, стандартная библиотека
- Qt 6 (Widgets)
- CMake
- Visual Studio 2022 (MSVC)

## Структура проекта

```
include/       заголовочные файлы ядра
include/gui/   заголовочные файлы интерфейса
src/           исходный код ядра (библиотека core, без Qt)
src/gui/       исходный код интерфейса (Qt Widgets)
CMakeLists.txt
CMakePresets.json
```

Ядро (`core`) не зависит от Qt и содержит всю бизнес-логику; интерфейс (`dryclean`) работает только через фасад `DryCleaningShop`.

## Сборка (Windows, Visual Studio 2022)

1. Установите Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений на C++».
2. Установите Qt 6 с компонентом MSVC 2022 64-bit.
3. Создайте файл `CMakeUserPresets.json` рядом с `CMakePresets.json` и укажите свой путь к Qt:

   ```json
   {
     "version": 3,
     "configurePresets": [
       {
         "name": "local-debug",
         "inherits": "x64-debug",
         "cacheVariables": {
           "CMAKE_PREFIX_PATH": "C:/Qt/6.12.0/msvc2022_64"
         }
       }
     ]
   }
   ```

4. Откройте папку проекта в Visual Studio (Файл → Открыть → Папка), выберите конфигурацию и соберите проект. После сборки `windeployqt` автоматически копирует библиотеки Qt рядом с `dryclean.exe`.
5. Запустите `dryclean.exe`.

## Запуск на другом компьютере

Соберите конфигурацию Release и передайте папку с `dryclean.exe` целиком (вместе с библиотеками Qt и подпапками, например `platforms/`). Устанавливать Qt или компилятор на целевом компьютере не нужно.
