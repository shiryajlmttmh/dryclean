# Информационная система химчистки

Курсовой проект по дисциплине «Программирование на языках высокого уровня» (БГУИР, 2026).

Настольное приложение на C++20 и Qt 6 для небольшой химчистки: учёт клиентов, изделий и заказов, расчёт стоимости и сроков, умный планировщик партий обработки, складской учёт расходных материалов, локальное хранение данных.

## Возможности

- Ведение картотеки клиентов (поиск по телефону и подстроке имени).
- Приём заказов с маркировкой изделий и фиксацией пятен и состояния.
- Полиморфный расчёт стоимости и срока по видам услуг (сухая чистка, влажная чистка, выведение пятен, кожа и мех).
- Цепочка статусов заказа: Принят → В обработке → Готов → Выдан.
- Планировщик партий: совместимость по ткани, цвету и режиму, вместимость машин, остатки материалов, объяснение конфликтов.
- Складской учёт с автоматическим списанием при подтверждении плана.
- Роли сотрудников: приёмщик, оператор, администратор.
- Атомарное сохранение данных в локальные файлы (поколения снимка и указатель CURRENT).

## Сборка (Windows, Visual Studio 2022)

1. Установите Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений на C++».
2. Установите Qt 6 с компонентом MSVC 2022 64-bit.
3. Создайте файл `CMakeUserPresets.json` рядом с `CMakePresets.json` и укажите свой путь к Qt:

   ```json
   {
     "version": 3,
     "configurePresets": [
       {
         "name": "local-debug",
         "inherits": "x64-debug",
         "cacheVariables": {
           "CMAKE_PREFIX_PATH": "C:/Qt/6.12.0/msvc2022_64"
         }
       }
     ]
   }
   ```

4. Откройте папку проекта в Visual Studio (Файл → Открыть → Папка), выберите конфигурацию и соберите проект.
5. Запустите `dryclean.exe`.
